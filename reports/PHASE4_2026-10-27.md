# Phase 4 — Authentication and authorization

## 1. Summary (5 lines)

Added optional register, login, refresh, logout, account identity, and role-gated admin endpoints.  
Passwords use BCrypt; 15-minute JWT access tokens stay in frontend memory, while rotating refresh tokens are hash-stored and sent in HttpOnly, SameSite=Strict cookies.  
Flyway V1 and a local MySQL compose service add the trimmed account schema; auth remains disabled by default.  
Frontend sign-in, registration, guest mode, silent refresh, protected account route, and logout are implemented.  
Auth acceptance cases are covered by backend tests; a live MySQL/browser run remains unverified.
