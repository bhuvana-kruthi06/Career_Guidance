## 5. How to run and test

Generate data first using README’s O*NET/ESCO pipeline. Copy `.env.example` to `.env`, change both local MySQL passwords, then `docker compose up --build` from project root. Open `http://localhost:8080`; API health is `http://127.0.0.1:8091/api/health`, OpenAPI JSON `http://127.0.0.1:8091/v3/api-docs`, Swagger UI `http://127.0.0.1:8091/swagger-ui/index.html`. For account E2E, set `AUTH_ENABLED=true`, `VITE_AUTH_ENABLED=true`, and a private `JWT_SECRET` in `.env` before building; install Chromium with `npx playwright install chromium`, set `PLAYWRIGHT_BASE_URL=http://127.0.0.1:8080`, and run `npm run test:e2e` from `frontend/`.
