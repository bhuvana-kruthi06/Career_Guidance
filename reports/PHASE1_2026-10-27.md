## 5. How to run and test

See the updated README Quick Start. In brief, download O*NET 31.0 and ESCO v1.2.1 source files into `data/raw/`, then from the project root run:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe data_processing\clean_data.py
.\venv\Scripts\python.exe data_processing\normalize_skills.py
.\venv\Scripts\python.exe data_processing\build_career_skill_map.py
.\venv\Scripts\python.exe frontend\scripts\export_skills.py
```

Start the API with `.\start_backend.ps1` and the frontend in another terminal with `Set-Location frontend; npm ci; npm run dev`. If Maven is not on PATH, set `MAVEN_CMD` to the full `mvn.cmd` path.

Run the suites and live smoke check with:

```powershell
.\venv\Scripts\python.exe -m pytest --basetemp .pytest-workspace-temp
$maven = if ($env:MAVEN_CMD) { $env:MAVEN_CMD } else { 'mvn' }
& $maven -f backend\pom.xml test
Set-Location frontend
npm test -- --run
npm run build
Set-Location ..
python scripts\smoke_test.py
```
